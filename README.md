# Hugh C. Williamson

I’m Hugh Cordova Williamson, an AI product builder in Tampa, Florida. I build search tools for field technicians and work on the software that teams use to plan and release changes.

## Can a technician trust the answer?

A technician asks a search tool how to export an inspection log. The answer gives a menu path and cites a real manual. The catch is that the manual belongs to the next model up. In [The right answer in the wrong manual](https://medium.com/@hughwilliamson827/the-right-answer-in-the-wrong-manual-e1e4854af94c), I use two fictional manuals to show how to catch that mistake and when the tool should ask which model the technician has.

## Selected work

- **Field knowledge search.** I built a tool that retrieves passages from service manuals and training videos. When I evaluate an answer, I check whether its source applies to the equipment in the question and actually supports the instruction.
- **Delivery reporting.** I brought ServiceNow and Azure DevOps records into a Power BI dashboard for weekly planning. I packaged it as a template and taught the team how to maintain it.
- **Software releases.** I designed a workflow where a coding agent proposes a change, automated checks run, and a reviewer can try a preview before approving the release.
